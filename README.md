# Quantum Cat ($Schrodinger)

Official website for Quantum Cat, a Solana meme coin. Static site (no build step), hosted on Vercel at https://schrodingerqcat.lol

## Edit later
Everything lives in `js/config.js`:
- `X_URL`: the official X account link (change it here when the handle is renamed).
- `CA`: paste the Solana contract address at launch. The DexScreener chart, PumpSwap buy links and the Copy button switch on automatically.

Pushing to `main` deploys to production.
